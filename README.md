# Portfolio Java
This is a simple portfolio project built using Java. It showcases various features and functionalities that can be implemented in a Java application.

## Stack
- Java
- Maven
- Spring Boot
- Thymeleaf
- PostgresSQL
- Bootstrap
- HTML/CSS

## Installation
1. Clone the repository:
   ```bash
   git clone
    ```
2. Navigate to the project directory:
   ```bash
   cd portfolio-java
   ```
3. Build the project docker compose:
   ```bash
   docker-compose up --build
   ```

## Features
- User authentication and authorization
- CRUD operations for portfolio items
- Responsive design using Bootstrap
- Integration with PostgreSQL database
- Thymeleaf templates for dynamic content rendering
- Admin panel for managing portfolio items
